# 09: Select & Combobox Primitives (Modern & Pixel Flavors)

**What to build:** Dropdown selection primitives: `<Select>` (accessible single-item dropdown) and `<Combobox>` (searchable filtered dropdown with live text filtering) in both Modern and Pixel flavors. Includes popup positioning, keyboard arrow navigation, Escape key dismissal, outside-click detection, and scrollable option lists.

**Blocked by:** 01 (Foundation Tokens), 02 (Button), 03 (Input)

**Status:** ready-for-agent

- [ ] Implement headless accessible popover positioning and focus trapping.
- [ ] Implement Modern Select and Combobox with floating menus, smooth micro-animations, and clean focus highlights.
- [ ] Implement Pixel Select and Combobox with stepped 3D pixel window borders, retro cursor indicator (e.g. `▶`), and pixel search input.
- [ ] Support keyboard navigation (Arrow Down/Up, Enter to select, Escape to close).
- [ ] Provide interactive showcase preview for both components.
