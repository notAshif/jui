# Stepped 3D Pixel Bevel Mechanics

We decided to construct 2D Pixel Components using a multi-layer stepped 3D light-source bevel model: an outer deep espresso `#4B2E2B` contour, top-and-left highlights in cream `#FFF8F0` or caramel `#C08552`, bottom-and-right depth shadows in cinnamon `#8C5A3C`, and a tactile 2px down-and-right translation upon active press. This replicates authentic 16-bit RPG tactile depth and physical arcade button mechanics in pure accessible CSS without canvas or bitmap sprite overhead.
