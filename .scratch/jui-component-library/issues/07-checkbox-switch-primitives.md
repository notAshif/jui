# 07: Checkbox & Switch/Toggle Primitives (Modern & Pixel Flavors)

**What to build:** Accessible binary selection controls: Checkbox and Switch/Toggle in both Modern and Pixel flavors. Checkbox supports checked, unchecked, and indeterminate states with keyboard activation. Switch supports smooth sliding transitions for Modern and tactile stepped lever flip mechanics for Pixel.

**Blocked by:** 01 (Foundation Tokens, Typography & Utilities)

**Status:** ready-for-agent

- [ ] Implement Modern Checkbox with smooth check animation and accessible focus rings.
- [ ] Implement Pixel Checkbox with stepped pixel frame and 8-bit chunky "X" or square fill checkmark.
- [ ] Implement Modern Switch with smooth thumb sliding animation.
- [ ] Implement Pixel Switch with stepped toggle track and physical tactile arcade lever snap feedback.
- [ ] Support full keyboard Space/Enter interaction and `aria-checked` states across both flavors.
- [ ] Provide interactive showcase preview for both components.
