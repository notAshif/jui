# 04: Label & Badge Primitives (Modern & Pixel Flavors)

**What to build:** Form Label primitives and status/tag Badge primitives in both Modern and Pixel flavors. Labels provide accessible association to form controls and disabled/required indicators. Badges provide compact visual indicators supporting multiple semantic status variants (`default`, `secondary`, `success`, `warning`, `destructive`, `outline`).

**Blocked by:** 01 (Foundation Tokens, Typography & Utilities)

**Status:** ready-for-agent

- [ ] Implement Modern and Pixel Label primitives with `htmlFor` association, required asterisks, and muted disabled states.
- [ ] Implement Modern Badge with smooth pill/rounded shapes and refined typography.
- [ ] Implement Pixel Badge with stepped pixelated outline frame and 8-bit chip styling.
- [ ] Support status variants (`default`, `secondary`, `success`, `warning`, `destructive`, `outline`) across both flavors.
- [ ] Provide interactive showcase preview for both components.
