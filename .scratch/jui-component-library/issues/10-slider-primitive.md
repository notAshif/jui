# 10: Slider Primitive (Modern & Pixel Flavors)

**What to build:** Accessible numeric range input primitive (`<Slider>`) in both Modern and Pixel flavors. Supports min/max bounds, custom step increments, keyboard arrow key adjustments, mouse/touch dragging, and visual fill progress.

**Blocked by:** 01 (Foundation Tokens, Typography & Utilities)

**Status:** ready-for-agent

- [ ] Implement Modern Slider with smooth track, round thumb with hover elevation, and sleek filled bar.
- [ ] Implement Pixel Slider with chunky stepped pixel track, square pixel thumb with tactile bevels, and retro integer value label.
- [ ] Support keyboard arrow key increments (Left/Down to decrement, Right/Up to increment, PageUp/PageDown).
- [ ] Support ARIA attributes (`aria-valuenow`, `aria-valuemin`, `aria-valuemax`).
- [ ] Provide interactive showcase preview demonstrating volume, sensitivity, and range controls.
