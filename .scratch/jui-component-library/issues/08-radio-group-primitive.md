# 08: Radio Group Primitive (Modern & Pixel Flavors)

**What to build:** Accessible mutually exclusive selection controls: `<RadioGroup>` and `<RadioGroupItem>` in both Modern and Pixel flavors. Supports arrow-key roving focus, accessible ARIA radio role contracts, and distinct modern vs pixel indicators.

**Blocked by:** 01 (Foundation Tokens, Typography & Utilities), 04 (Label & Badge Primitives)

**Status:** ready-for-agent

- [ ] Implement Modern Radio Group with circular indicators and smooth selection dot transitions.
- [ ] Implement Pixel Radio Group with diamond or square stepped pixel frames and retro filled dot indicators.
- [ ] Implement arrow key (Up/Down/Left/Right) roving tabindex navigation.
- [ ] Support disabled radio items and disabled group states.
- [ ] Provide interactive showcase preview for both flavors.
