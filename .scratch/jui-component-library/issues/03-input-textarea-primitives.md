# 03: Input & Textarea Primitives (Modern & Pixel Flavors)

**What to build:** Text input and multi-line textarea form primitives in both Modern and Pixel flavors sharing uniform prop interfaces. Supports placeholder text, disabled states, interactive focus rings, integrated error state styling (rustic terracotta border and focus glow), and helper text slots.

**Blocked by:** 01 (Foundation Tokens, Typography & Utilities)

**Status:** ready-for-agent

- [ ] Implement Modern Input and Textarea with sleek borders, subtle rounded corners, and focus states.
- [ ] Implement Pixel Input and Textarea with inset stepped pixel frame shadows, 0px border radius, and retro typography.
- [ ] Support error state styling with automatic accessible `aria-invalid` propagation and error message linking.
- [ ] Support disabled states with muted styling and interaction suppression.
- [ ] Provide interactive showcase preview demonstrating normal, focused, error, and disabled states in both flavors.
