# 05: Card & Separator Primitives (Modern & Pixel Flavors)

**What to build:** Structural container and division primitives. Card provides compound components: `<Card>`, `<CardHeader>`, `<CardTitle>`, `<CardDescription>`, `<CardContent>`, and `<CardFooter>`. Separator provides horizontal and vertical divider lines with accessible `role="separator"` semantics.

**Blocked by:** 01 (Foundation Tokens, Typography & Utilities)

**Status:** ready-for-agent

- [ ] Implement Modern Card compound components with subtle borders, elevation shadows, and clean typography.
- [ ] Implement Pixel Card with chunky stepped pixel window borders, nostalgic RPG dialog box styling, and retro title headers.
- [ ] Implement Modern Separator with subtle borders and Pixel Separator with dashed/pixelated stepped divider rules.
- [ ] Support both horizontal and vertical orientation for Separator with ARIA orientation attributes.
- [ ] Provide interactive showcase preview for both components.
